# YouTube CDN Fix (googlevideo)

Расширение для Chrome, которое помогает, когда видео на YouTube встаёт на
середине (чаще всего — Shorts) из-за проблемного CDN-узла `googlevideo.com`.

## Что оно делает

1. Content-script на страницах YouTube следит за элементом `<video>`.
2. Если время воспроизведения не двигается больше 3 секунд, а данные не
   подгружаются (`readyState <= 2`), расширение считает это зависанием.
3. Из `performance.getEntriesByType('resource')` оно берёт свежие запросы к
   `*.googlevideo.com` и выбирает самый «висящий» узел (наибольшая
   длительность запроса).
4. Через `declarativeNetRequest` этот узел временно блокируется
   (`block`), плеер получает ошибку и переключается на другой узел из списка.
5. Через N минут (по умолчанию 90 секунд) блокировка снимается автоматически,
   чтобы не мешать видео, которые лежат в кэше этого же узла.

Кэшированные видео не зависают — значит, блокировка их и не коснётся.

## Почему не `webRequest`

В Chrome события `webRequest` **не приходят** для медиа-запросов YouTube
(проверено: запросы видны в DevTools → Network, но не в расширении).
Поэтому старая схема «считать ошибки сети» не работала, и попап всегда был
пустой. Версия 2.0 определяет зависание по самому `<video>` и по таймингам
ресурсов — это работает.

## Что расширение не может

Если провайдер режет TLS до внешних узлов Google (а в РФ это так), то сам по
себе обход CDN не поможет: переключиться просто некуда. Нужен обход DPI —
например, zapret с настройкой `fake,fakedsplit` + `badseq` для
`googlevideo.com`. Расширение и обход DPI дополняют друг друга:

- zapret пробивает TLS до узлов Google;
- расширение убирает сломанный узел, чтобы плеер не ждал его по 10–20 секунд.

## Настройки

- **Держать блокировку, минут** — сколько узел остаётся заблокированным.
  `0` — до перезапуска браузера.
- **Максимум узлов сразу** — предохранитель, чтобы случайно не заблокировать
  все узлы.

## Установка

1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать эту папку.

## Права

- `declarativeNetRequest` — блокировка узлов.
- `storage`, `alarms` — состояние и автоснятие блокировок.
- `activeTab` — показать состояние текущей вкладки в попапе.
- `host_permissions: *://*.googlevideo.com/*` — только домены CDN Google.
